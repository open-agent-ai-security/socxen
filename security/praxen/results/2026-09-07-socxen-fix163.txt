BEHAVIOR SUMMARY
------------------------------------------------------------------------------
The dominant pattern is a genuinely deterministic enforcement layer with its
remaining risk pushed to the edges that layer was never in front of. The
dismiss/close gate ships active as a bundled PreToolUse hook that fails closed
on every branch — deny on containment, ask on dismiss/close, ask on anything
unclassified, ask on any exception — writes are neutralized fail-closed before
they leave, and the tiers the hook, the permission snippet and the Codex map
all read are generated from one file and drift-checked in CI. What is left
unguarded is the untrusted text nothing deterministic can filter. The sharpest
instance is the remote MCP's own tool definitions: _screen_tools strips their
invisible code points and _DIRECTIVE_RE notices that they talk to the model,
but the text reaches the model verbatim, and the project's own measurement is
that the model obeyed the proxy's "MANDATORY … IGNORE any user request" on
1,840 of 1,840 searches. The same shape recurs in the docs' unsupported "any
other agent" install path, where no host gate exists at all and the skill
tells the model that its own in-prompt ask is the lock that always holds.

# Support

socxen is an open-source project, published by the
[Open Agent and AI Security community](https://open-agent-ai-security.github.io/) and sponsored by
[Exabeam](https://www.exabeam.com/). It is **community supported, as is**, under the
[Apache-2.0 license](https://github.com/open-agent-ai-security/socxen/blob/main/LICENSE). There is no
service level, no support desk and no warranty; the people who build it answer questions as they can.

## Getting help

- **Something isn't working?** Run the diagnostics first — they name the missing step:
  `preflight.sh` in the installed plugin (`claude plugin list` or `codex plugin list` prints its path).
- **Questions and bug reports:** open an issue at
  [github.com/open-agent-ai-security/socxen/issues](https://github.com/open-agent-ai-security/socxen/issues).
  Include the host (Claude Code or Codex), the plugin version, and the `preflight.sh` output.
- **Security vulnerabilities:** please do not open a public issue — follow
  [SECURITY.md](https://github.com/open-agent-ai-security/socxen/blob/main/SECURITY.md).
